# 의대협 장학 공고 수집기

여러 곳에 흩어진 장학 공고를 하루 두 번 자동으로 모아, 관리자가 한 페이지에서 보고 홈페이지 장학금 게시판에 옮겨 적을 수 있게 해 주는 도구입니다. 홈페이지(kmsa.or.kr)에는 아무것도 설치하지 않으며, 수집과 페이지 생성은 모두 GitHub에서 무료로 돌아갑니다.

모으는 대상은 대학과 상관없이 의대생이 지원할 수 있는 장학금입니다. 특정 대학이 자기 학생에게 주는 교내 장학금과, 이공계·간호·약학·치의학·한의학 전용처럼 의대생이 지원할 수 없는 장학금은 자동으로 뺍니다. 남은 공고는 두 가지로 표시됩니다. "의대 관련"은 의대생 전용이거나 지원 대상에 의대생이 명시된 장학금이고, "전공 무관"은 지자체 인재장학금이나 소득 기준 재단 장학금처럼 전공 제한이 없어 의대생도 지원할 수 있는 장학금입니다.

결과 페이지는 마감 임박순으로 정렬되고, 새로 발견된 공고에는 NEW가 붙습니다. 각 공고의 "게시용 복사" 버튼을 누르면 기관, 신청기간, 대상, 금액, 원문 링크가 정리된 문구가 복사되므로 그대로 게시판 글쓰기에 붙여 넣고 다듬으면 됩니다. 게시한 공고는 "게시 완료"에 체크해 두면 흐리게 표시됩니다(체크 상태는 각자 쓰는 브라우저에만 저장됩니다).

## 어디서 모으나

1. 한국장학재단 학자금지원정보(공공데이터포털): 지자체, 민간재단, 기업 등의 장학금이 모집기간과 함께 정리된 공식 데이터입니다. 매달 갱신되며, 마감이 지나지 않은 것만 가져옵니다. 운영기관이 대학인 항목은 제외합니다.
2. 네이버 뉴스 검색 API: 의료 전문지 등에 실린 의대생 장학생 모집 기사를 잡습니다. "장학금 전달·기탁" 같은 기사는 걸러집니다.
3. 장학재단·기관 공지 게시판: 의대생 대상인 (재)보건장학회, 아산사회복지재단(의생명과학분야), 공공보건의료교육훈련센터(공중보건장학)와, 전공 무관인 관정이종환교육재단, 종근당고촌재단, 우양재단, DB김준기문화재단이 들어 있습니다. DB김준기문화재단은 게시글 링크가 자바스크립트로 되어 있어 목록의 제목만 읽고, 링크는 공지 목록 페이지로 연결됩니다.

자동 수집이 안 되는 재단(서울장학재단, 롯데장학재단, 서암윤세영재단, 유한재단)은 `sources.yaml` 주석에 적어 두었습니다. 이곳들은 사람이 직접 확인하거나, 주소를 확인한 뒤 추가해야 합니다.

게시판 글과 기사는 제목에 "장학"이나 "학자금"이 있고 "결과, 합격자, 수여식, 교내" 같은 단어가 없는 것만 남기며, 새 공고는 상세 페이지를 한 번 열어 신청기간, 지원대상, 지원금액을 뽑습니다. 같은 공고가 여러 곳에 올라오면 한 줄로 묶습니다. 모든 요청은 각 사이트의 robots.txt를 지키고, 같은 사이트에는 2초 간격을 둡니다.

## 처음 설정 (약 20분)

1. GitHub에 비공개 저장소를 하나 만들고 이 폴더의 파일을 모두 올립니다(`.github` 폴더 포함).
2. 공공데이터포털(data.go.kr)에서 "한국장학재단_학자금지원정보(대학생)"을 검색해 오픈 API 활용신청을 합니다. 승인되면 마이페이지에서 "일반 인증키(Decoding)"를 복사합니다.
3. 네이버 개발자센터(developers.naver.com)에서 애플리케이션을 등록하고 "검색" API를 선택해 Client ID와 Client Secret을 받습니다. 원하지 않으면 건너뛰어도 됩니다.
4. 저장소의 Settings → Secrets and variables → Actions → New repository secret에서 아래 이름으로 등록합니다.
   - `DATA_GO_KR_KEY`: 공공데이터포털 인증키
   - `NAVER_CLIENT_ID`, `NAVER_CLIENT_SECRET`: 네이버 키
   - `ANTHROPIC_API_KEY`: 선택. 등록하면 공고문에서 기간·대상·금액을 Claude가 한 번 더 읽어 정확도를 높입니다. 새 공고에만 쓰므로 비용은 아주 적습니다.
5. Actions 탭에서 "장학 공고 수집"을 고르고 Run workflow를 누릅니다. 1~3분 뒤 `docs/index.html`이 만들어집니다. 이후로는 매일 오전 7시, 오후 4시쯤 자동으로 돌아갑니다.

## 결과 보는 법

가장 간단한 방법은 저장소의 `docs/index.html`을 내려받아 브라우저로 여는 것입니다. 매번 내려받기 번거로우면 Settings → Pages에서 Branch를 `main`, 폴더를 `/docs`로 지정해 웹 주소로 볼 수 있습니다. 다만 무료 요금제에서는 Pages를 쓰려면 저장소가 공개여야 하고, 그러면 페이지도 공개됩니다. 담긴 내용은 이미 공개된 장학 공고뿐이고 검색엔진 노출은 막아 두었지만, 공개가 부담스러우면 내려받아 보는 방식을 쓰세요. 엑셀로 보고 싶으면 `docs/scholarships.csv`를 쓰면 됩니다.

페이지 맨 아래 "수집 현황"을 열면 출처마다 정상인지, 몇 건을 가져왔는지, 실패했다면 이유가 무엇인지 나옵니다. "확인 필요"는 게시판에서 글을 하나도 읽지 못했다는 뜻으로, 사이트 구조가 바뀌었을 가능성이 큽니다. 새 출처를 추가한 뒤에는 여기서 먼저 확인하세요.

## 수집처 늘리기

`sources.yaml` 파일의 `sources:` 아래에 항목을 추가하면 됩니다. 의대생 장학금을 직접 공고하는 재단이나 기관(보건장학회, 아산사회복지재단, 관정이종환교육재단, 각 시도 장학재단 등)의 공지 게시판을 하나씩 넣는 것이 가장 효과적입니다.

대학 게시판은 교내 장학금이 너무 많아 기본으로 꺼 두었습니다. 학교 게시판에만 올라오는 외부 재단 공고까지 잡고 싶으면 `enabled: false`를 지우고 켜면 됩니다. 교내 장학금과 다른 전공 전용 공고는 그래도 자동으로 걸러집니다. 주소에 `/bbs/.../artclList.do`가 들어 있는 게시판은 `artclList.do`를 `rssList.do?row=50`으로 바꾼 주소를 rss로 넣습니다.

워드프레스로 만든 사이트는 게시판 주소 끝에 `/feed/`를 붙이면 RSS가 됩니다. RSS가 없는 게시판은 `html_list`로 넣고, 게시글 링크 주소에 공통으로 들어가는 부분을 `link_pattern`에 적습니다. 그누보드 게시판이라면 `wr_id=\\d+`입니다.

```yaml
  - name: OO장학재단 공지
    type: html_list
    url: https://oo-foundation.or.kr/bbs/board.php?bo_table=notice
    link_pattern: "wr_id=\\d+"
```

수집 결과가 너무 많거나 적으면 `settings`의 `include_keywords`, `exclude_keywords`를 조정하세요.

## 주의할 점

자동으로 뽑은 기간과 금액은 틀릴 수 있습니다. 홈페이지에 올리기 전에 반드시 원문 공고와 대조해 주세요. 게시판에는 공고문 전문이나 첨부파일을 옮기지 말고, 요약과 원문 링크만 올리는 것이 저작권과 각 사이트 이용약관 면에서 안전합니다. 어떤 사이트가 수집을 막고 있으면(robots.txt) 수집 현황에 "robots 차단"으로 표시되며, 그 사이트는 사람이 직접 확인해야 합니다.

## 내 컴퓨터에서 실행하기

Python 3.10 이상에서 `pip install -r requirements.txt` 후 `python crawler.py`를 실행하면 됩니다. 키는 환경변수로 넣습니다(예: `DATA_GO_KR_KEY=... python crawler.py`). 테스트는 `pip install pytest` 후 `python -m pytest tests`입니다.
